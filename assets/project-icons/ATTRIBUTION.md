# Project technology icons

The bundled brand icons are unmodified SVGs from [Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0), under the included MIT license. Original file URLs are recorded in tech-catalog.js. Brand names and logos belong to their respective owners and identify the tools entered by the user.

generic.svg is an original neutral code symbol used when a technology has no bundled logo.
